
# CodeAlpha Project: Basic Chatbot

## Introduction
The Basic Chatbot is a simple Python program that communicates with users through text messages. It provides predefined replies according to the user's input.

## Objective
The objective is to create a simple interactive chatbot using Python programming concepts.

## Features
- Greets users
- Responds to greetings
- Answers how are you
- Provides its name
- Displays help instructions
- Ends the conversation when the user types bye

## Technologies Used
- Python
- VS Code

## Concepts Used
- If-elif-else statements
- Functions
- While loops
- User input
- String methods

## How to Run
1. Open the project in VS Code.
2. Open the terminal.
3. Type: python chatbot.py
4. Press Enter.

## Conclusion
This project helped me understand conditional statements, loops, functions and user interaction in Python.
