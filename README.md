
# 🤖 Basic Chatbot Using Python

## 📌 About the Project
This Basic Chatbot is developed using Python as part of my CodeAlpha Internship.

The chatbot interacts with users and provides predefined responses to simple messages and questions.

## ✨ Features
- Responds to greetings such as Hello, Hi, and Hey.
- Answers basic questions.
- Introduces itself when asked for its name.
- Responds to help requests.
- Handles unknown messages with a default response.
- Ends the conversation when the user types "bye".

## 🛠️ Technologies Used
- Python
- While Loop
- If-Else Statements
- String Handling

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Make sure Python is installed.
4. Run the following command:

```bash
python chatbot.py
```

## 💻 Example Interaction

```text
Welcome to Basic Chatbot!
Type 'bye' to exit.

You: Hello
Bot: Hello! How can I help you?

You: How are you
Bot: I am fine! How are you?

You: bye
Bot: Goodbye! Have a nice day!
```
